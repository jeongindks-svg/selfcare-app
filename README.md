# 자기관리

러닝·팔굽혀펴기 같은 운동, 수면, 가계부, 신앙 활동을 기록하고 **능력치**로 한눈에 보는 개인용 웹앱이에요.
서버도 계정도 없어요. 기록은 내 브라우저(localStorage)에만 저장돼요.

- 오늘의 체크, 분야별 기록, 8주 능력치 그래프, 통계(5주 달성 기록)
- 운동 종목 추가·삭제, 목표 수정 / 수면 10점 별점과 "나에게 맞는 수면" 분석 / 가계부 카테고리·예산 / 신앙 항목·기도 제목
- 라이트·다크 모드, 오프라인 사용(PWA), JSON 백업·복원
- 외부 서버 요청이 없어요 (폰트·분석 도구·광고 없음)

## GitHub Pages로 올리는 방법

1. GitHub에서 새 저장소(Repository)를 만들어요. 이름은 자유예요. 공개(Public)로 만들면 무료 Pages를 쓸 수 있어요.
2. 이 폴더 안의 파일을 **폴더째가 아니라 파일 그대로** 저장소 맨 위에 올려요.
   (`index.html`이 저장소 맨 위에 있어야 해요. 웹에서 **Add file → Upload files**로 끌어다 놓으면 돼요. 숨김 파일 `.nojekyll`도 같이 올리면 좋아요.)
3. 저장소의 **Settings → Pages**로 가요.
4. **Build and deployment**에서 Source를 **Deploy from a branch**로 하고, Branch를 `main` / `(root)`로 선택한 뒤 Save를 눌러요.
5. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소로 열려요.

터미널을 쓴다면:

```bash
git init
git add .
git commit -m "자기관리 앱"
git branch -M main
git remote add origin https://github.com/내아이디/저장소이름.git
git push -u origin main
```

## 폰에서 앱처럼 쓰기

- **iPhone (Safari)**: 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome)**: 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**

## 내 컴퓨터에서 미리 보기

서비스 워커와 설치 기능은 `file://`이 아닌 주소에서만 동작해서, 간단한 서버로 열어 보세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

## 데이터 저장과 백업

- 기록은 **브라우저별·기기별**로 따로 저장돼요. 폰과 컴퓨터는 서로 이어지지 않아요.
- 브라우저의 사이트 데이터를 지우면 기록도 사라져요. **설정 → 데이터 내보내기**로 가끔 백업해 두세요.
- 다른 기기로 옮길 때는 한쪽에서 내보내고, 다른 쪽에서 **데이터 가져오기**를 쓰면 돼요.
- iPhone Safari는 오래 쓰지 않은 사이트의 데이터를 정리할 수 있어요. 홈 화면에 추가해서 쓰면 더 안전하고, 백업은 습관으로 해 두는 걸 권해요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 틀 |
| `style.css` | 디자인. 맨 위 `:root`에서 색상 변수를 바꿀 수 있어요 |
| `app.js` | 앱 전체 로직 (기록 저장, 능력치 계산, 차트, 화면) |
| `sw.js` | 오프라인 캐시. 파일을 고쳐 올렸다면 안의 `CACHE` 버전 숫자를 올려 주세요 |
| `manifest.webmanifest`, `icon*.png`, `icon.svg`, `apple-touch-icon.png` | 홈 화면 설치용 설정과 아이콘 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서비스하도록 하는 빈 파일 |

## 직접 고쳐 쓰기

- **능력치 계산식**: `app.js`의 `abilitiesAt` 함수 (체력·근력은 하루 목표 달성률, 회복은 수면 시간과 별점, 꾸준함은 체크 달성률, 재정은 예산 준수와 기록, 신앙은 항목 실천률의 최근 7일 평균)
- **기본 종목·카테고리·신앙 항목**: `app.js`의 `defaultState` 함수 (앱을 처음 열 때 쓰이는 값. 이미 쓰던 브라우저에는 저장된 값이 우선이에요)
- **색상**: `style.css` 맨 위의 변수
