# Growth — 자기관리

러닝·팔굽혀펴기 같은 운동, 수면, 가계부, 신앙, 버킷리스트, 위시리스트를 기록하고 **Growth 점수**와 **주간 리뷰**로 한눈에 보는 개인용 웹앱이에요.
기록은 먼저 내 기기(브라우저)에 저장돼요. 원하면 **폰·태블릿·컴퓨터를 연결**해서 같은 기록을 볼 수 있어요.

## 폰 · 태블릿 · 컴퓨터를 연결하기 (기기 간 동기화)

설정 → **기기 간 동기화** → **다른 기기와 연결하기**

기록을 내 GitHub 계정의 **비공개 Gist**에 올려서 기기들이 나눠 써요. 따로 서버를 두지 않아도 되고, 모든 기기에서 같은 GitHub 토큰과 같은 비밀번호만 입력하면 돼요.

1. **토큰 만들기** (한 번만): 연결 창의 “GitHub 토큰 만들기” 링크를 누르면 `gist` 권한만 선택된 새 토큰 화면이 열려요. 만료 기간을 길게 정하고 만든 뒤 `ghp_…` 토큰을 복사하세요. (GitHub → Settings → Developer settings → Personal access tokens (classic)에서도 만들 수 있어요.)
2. **첫 번째 기기**: 토큰과 새 비밀번호(6자 이상)를 두 번 입력해요. 기록이 있으면 Gist로 올라가요.
3. **다른 기기들**: 같은 토큰과 **같은 비밀번호**를 입력해요. 올라간 기록을 그대로 받아와요. 이 기기에 이미 기록이 있으면 양쪽을 합쳐요.
4. 그 뒤에는 자동이에요. 기록을 고치면 잠시 뒤 올라가고, 앱을 다시 열거나 화면으로 돌아올 때 1분 안팎으로 최신 기록을 받아요. 설정의 “지금 동기화”로 바로 맞출 수도 있어요.

**안전하게 쓰는 법**
- 기록은 **비밀번호로 암호화**(PBKDF2 → AES-256-GCM)해서 올라가요. Gist에는 암호문만 보여요.
- 토큰과 비밀번호는 **그 기기에만** 저장돼요. 백업 파일과 동기화 데이터에는 들어가지 않아요.
- **비밀번호를 잃어버리면 클라우드 기록은 복구할 수 없어요.** 가끔 “데이터 내보내기”로 백업해 두세요.
- 연결을 끊으려면 설정의 “이 기기 연결 해제”. 올라간 Gist는 GitHub의 gist.github.com에서 직접 지울 수 있어요.

**두 기기에서 동시에 고쳤다면**
- 기록(러닝·수면·지출·메모 등)은 양쪽 것을 **합쳐요**. 같은 기록을 양쪽에서 다르게 고쳤다면 더 늦게 고친 쪽을 따라요.
- 설정(목표, 카테고리 이름 등)은 더 최근에 고친 쪽을 따라요.
- 충돌 없이 한쪽에서 지운 기록은 다른 기기에서도 지워져요. 다만 **서로 오프라인으로 고친 뒤 합치는 순간**에는, 한쪽에서 지운 기록이 다른 쪽에 남아 있으면 되살아날 수 있어요.
- 화면 모드(라이트/다크)와 화면 배치는 기기마다 따로예요.

> Claude 안에서 열었을 때는 GitHub 대신 **내 Claude 계정**으로 자동 동기화돼요. 같은 Claude 계정으로 로그인한 기기끼리 실시간으로 이어져요.

## 화면 배치는 기기에 맞게

| | 폰 · 세로 | 태블릿 · 가로 |
| --- | --- | --- |
| 조건 | 너비 800px 미만, 높이 440px 미만, 또는 세로로 든 화면 | 가로로 든 화면에서 너비 800px 이상, 높이 440px 이상 |
| 이동 | 아래 탭 4개 | 왼쪽 사이드 메뉴에 모든 분야 |
| 배치 | 한 줄 | 너비 960px 이상이면 왼쪽·오른쪽 2단, 그보다 좁으면 넓은 한 줄 |
| 입력 창 | 아래에서 올라오는 시트 | 화면 가운데 대화창 |

창 크기를 직접 재서 정하기 때문에 화면을 돌리면 바로 바뀌어요. 태블릿에서 기대한 대로 안 나오면 설정 → **화면 배치**에서 `폰` / `태블릿`을 직접 고를 수 있어요(그 기기에만 적용). 설정에는 지금 인식한 화면 크기도 보여요.

## 러닝 기록

- **입력**: 날짜, 거리(km), 시간(분·초). 숫자 키패드로 바로 입력돼요. 초에 60 이상을 넣으면 분으로 올려요.
- **페이스로도 입력**: “시간 입력 방식”을 `페이스`로 바꾸면 1km당 페이스(분·초)를 넣어 총 시간을 계산해요. 시간 ↔ 페이스를 오가면 값이 자동으로 바뀌어요.
- 입력하는 동안 **페이스와 시속**(예: 5'42" /km · 10.5 km/h)을 바로 보여줘요.
- 기록 줄을 누르면 **수정**할 수 있어요(삭제는 수정 창 아래). 줄마다 `5.2 km · 29분 5초`와 `5'35" /km`가 보이고, “모든 기록 보기”로 오래된 기록도 고칠 수 있어요.
- 러닝은 합계가 아니라 **기록 중심**: 평균 페이스, 페이스 그래프, 거리별 기록(3km·5km·10km·하프)의 평균과 최고.
- 거리별 기록은 그 거리의 ±10% 안에서 달린 기록을 해당 거리로 환산한 값이에요. 평균은 최근 30일, 최고는 전체 기간 기준이에요.

## 구성

- **오늘**: 이번 주 Growth 한 줄 요약, 분야 4곳의 오늘 상태, 리스트 요약 한 줄.
- **분야**: `기록`(운동·수면·가계부·신앙)과 `리스트`(버킷리스트·위시리스트). 모든 분야 화면은 같은 순서예요: 기간 선택 → 핵심 카드 → 기록 추가 → 평균·최고 → 최근 기록 → 다른 분야와의 연결.
- **Growth**: 한 줄 요약 → 영역을 누르면 8주 막대 그래프와 계산 근거
- **리뷰**: 지난 7일 기록과 직전 주 비교(수면은 평균 평점), 분야 간 연결, 최근 5주 기록한 날.

## 분야가 서로 이어지는 곳

- **운동 ↔ 수면 ↔ 지출 ↔ 신앙**: 기록을 둘로 나눠 비교해요. 예) 운동한 날 다음 아침의 수면 평점, 잘 잔 날의 러닝 페이스, 잘 잔 날의 지출.
- **버킷리스트 ↔ 운동**: 운동 기록을 연결해 두면(한 번에 21.1km, 5km 28분 이내, 하루 100회 등) 기록이 목표에 닿을 때 자동으로 이뤄요.
- **위시리스트 ↔ 가계부**: 가격이 이번 달 남은 예산 안인지 표시하고, 구입하면 가계부에 지출로 남길지 물어봐요.
- **신앙 ↔ 가계부**: 신앙 화면에 이번 달 헌금·기부 금액이 나와요.

## 점수는 어떻게 계산하나요

점수는 "내가 정한 기준을 얼마나 지켰는지"를 0~100으로 보여줘요. 영역마다 기록이 3일 이상 쌓여야 점수가 나오고, 그 전에는 비워 둬요.

| 영역 | 계산 |
| --- | --- |
| 체력·근력 | 최근 7일 운동 합계 ÷ 주간 목표 (100점 상한) |
| 회복 | 기록한 밤 중 목표 수면 시간 이상 잔 밤의 비율 (평점은 점수에 넣지 않고 따로 표시) |
| 꾸준함 | 최근 7일 중 하나라도 기록한 날의 비율 |
| 재정 | 최근 30일 지출을 그 기간의 월 예산 몫과 비교 (예산 안이면 100점) |
| 신앙 | 켜 둔 항목을 최근 7일 동안 실천한 비율 |
| 종합 | 점수가 나온 영역의 평균 (2개 영역 이상) |

기본값으로 참고한 기준: 성인 수면 하루 7시간 이상(미국수면의학회·수면연구학회 권고), WHO 신체활동 권고(성인 주 150분 이상 유산소, 주 2일 이상 근력). 나머지는 내가 정한 목표가 기준이에요. 의학·재정 진단이 아니에요. 분야 간 연결은 최근 8주 기록을 둘로 나눠 평균을 비교한 값으로, 각 그룹이 4일 이상이고 차이가 뚜렷할 때만 보여주며 원인이 아니라 함께 나타난 경향이에요.

## GitHub Pages로 올리는 방법

1. GitHub에서 새 저장소(Repository)를 만들어요. 공개(Public)로 만들면 무료 Pages를 쓸 수 있어요. (기록은 저장소가 아니라 각자의 기기와 비공개 Gist에 있어요.)
2. 이 폴더 안의 파일을 **폴더째가 아니라 파일 그대로** 저장소 맨 위에 올려요. (`index.html`이 저장소 맨 위에 있어야 해요. 웹에서 **Add file → Upload files**로 끌어다 놓으면 돼요.)
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `(root)`로 선택하고 Save를 눌러요.
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소로 열려요. 폰·태블릿·컴퓨터에서 같은 주소를 열고 위의 동기화 연결을 하세요.

이미 올려 둔 저장소가 있다면 같은 이름의 파일을 덮어쓰기로 다시 올리면 돼요. 기록은 브라우저에 그대로 남아요. 동기화는 `https` 주소에서만 켤 수 있어요(GitHub Pages는 해당).

## 설치한 앱이 가로로 안 돌아가요 (안드로이드)

설치한 앱은 **설치할 때 받은 설정**을 계속 써요. 예전 버전의 `manifest.webmanifest`에 세로 고정이 들어 있었기 때문에, 그때 설치한 앱은 파일을 새로 올려도 세로로 남을 수 있어요. 현재 버전은 방향 잠금이 없고, 새 앱으로 인식되도록 설치 식별자(`id`)를 바꿨어요.

1. 새 파일을 GitHub에 올리고 1~2분 기다려요. 브라우저에서 `내 앱 주소/manifest.webmanifest`를 열어 `"id": "/?app=growth-v2"`가 보이고 `orientation`이 **없으면** 올라간 거예요.
2. 기존 설치 앱을 **삭제**해요. (설정 → 앱 → 자기관리 → 삭제. 홈 화면에서 아이콘만 지우는 것으로는 부족해요.)
3. Chrome에서 앱 주소를 열고 메뉴(⋮) → **앱 설치**를 눌러요. 식별자가 달라서 “이미 설치됨”이 아니라 새 앱으로 설치돼요.
4. 앱 설정 → 화면 배치 아래에 **앱 버전 9 · 설치한 앱 · 기기 방향**이 보이면 새 파일로 열린 거예요. 버전이 9보다 낮으면 아직 예전 파일이에요.
5. 기기를 가로로 돌리면 사이드 메뉴 화면이 나와요. 안 돌아가면 빠른 설정의 **자동 회전**이 켜져 있는지 확인하세요.

설치가 계속 안 되면 Chrome 메뉴의 **홈 화면에 추가 → 바로가기**로 만든 아이콘은 방향 잠금과 무관하게 가로로 돌아가요.

설정 → 화면 배치의 `태블릿`은 세로 상태에서도 사이드 메뉴 배치를 강제로 보여주는 선택이에요. 돌릴 때 알아서 바뀌게 하려면 `자동`으로 두세요.

## 폰·태블릿에서 앱처럼 쓰기

- **iPhone · iPad (Safari)**: 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome)**: 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**

## 데이터 저장과 백업

- 연결하지 않으면 기록은 **브라우저별·기기별**로 따로 저장돼요. 브라우저의 사이트 데이터를 지우면 기록도 사라져요.
- **설정 → 데이터 내보내기**로 가끔 백업해 두세요. 신앙 메모 같은 개인 기록도 같은 파일에 들어가니 보관에 주의하세요. “데이터 가져오기”로 되돌릴 수 있어요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 틀 (아래 탭, 사이드 메뉴 자리 포함) |
| `style.css` | 디자인. 맨 위 `:root`에서 색상 변수를 바꿀 수 있어요 |
| `app.js` | 앱 전체 로직 (동기화 `5b` 부분 포함) |
| `sw.js` | 오프라인 캐시. 파일을 고쳐 올렸다면 안의 `CACHE` 버전 숫자를 올려 주세요 |
| `manifest.webmanifest`, `icon*.png`, `icon.svg`, `apple-touch-icon.png` | 홈 화면 설치용 설정과 아이콘 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서비스하도록 하는 빈 파일 |

## 직접 고쳐 쓰기

- **화면 배치 기준 크기**: `app.js`의 `layoutMode` 함수
- **2단 나누는 위치**: 각 화면 함수 안의 `<!--cols-->`(2단 시작)와 `<!--col-->`(오른쪽 단 시작) 표식
- **동기화**: `syncCore`(판단 순서), `mergeStates`(합치기), `gistProv`(GitHub), `makeDbProvider`(Claude 계정)
- **점수 계산식**: `growthAt` 함수, 설명 문구는 `ABIL` 배열
- **분야 간 연결 분석**: `crossInsights` 함수 (최소 일수는 `LINK_MIN`)
- **러닝 거리별 기록 거리**: `RUN_DISTS` 배열
- **기본 종목·카테고리·신앙 항목**: `defaultState` 함수 (처음 여는 브라우저에만 적용돼요)
