# Growth — 자기관리

러닝·팔굽혀펴기 같은 운동, 수면, 가계부, 신앙, 버킷리스트, 위시리스트를 기록하고 **Growth 점수**와 **주간 리뷰**로 한눈에 보는 개인용 웹앱이에요.
서버도 계정도 없어요. 기록은 내 브라우저(localStorage)에만 저장돼요.

## 화면은 기기에 맞게 둘로 나뉘어요

| | 폰 · 세로 | 태블릿 · 가로 |
| --- | --- | --- |
| 조건 | 그 외 모든 화면 | 너비 900px 이상, 높이 540px 이상 (가로로 둔 태블릿, 데스크톱 브라우저) |
| 이동 | 아래 탭 4개 (오늘 · 분야 · Growth · 리뷰) | 왼쪽 사이드 메뉴에 모든 분야가 한 번에 (오늘 · Growth · 리뷰 / 운동 · 수면 · 가계부 · 신앙 / 버킷리스트 · 위시리스트 / 설정) |
| 배치 | 한 줄로 쌓기 | 제목·기간 선택은 위에 한 줄, 아래는 왼쪽·오른쪽 2단 (예: 수면은 왼쪽 그래프·기록, 오른쪽 분석·최근 기록) |
| 입력 창 | 아래에서 올라오는 시트 | 화면 가운데 대화창 |

화면을 돌리거나 창 크기를 바꾸면 자동으로 바뀌어요. 같은 데이터를 그대로 보여줘요.

## 구성

- **오늘**: 이번 주 Growth 한 줄 요약, 분야 4곳의 오늘 상태, 리스트 요약 한 줄. 기록은 각 분야에서 남겨요.
- **분야**: `기록`(운동·수면·가계부·신앙)과 `리스트`(버킷리스트·위시리스트). 모든 분야 화면이 같은 순서예요: 기간 선택 → 핵심 카드 → 기록 추가 → 평균·최고 → 최근 기록 → 다른 분야와의 연결.
- **Growth**: 한 줄 요약 → 영역을 누르면 8주 막대 그래프와 계산 근거
- **리뷰**: 지난 7일 기록과 직전 주 비교, 분야 간 연결, 최근 5주 기록한 날. 수면은 평균 평점으로 보여줘요.

## 분야가 서로 이어지는 곳

- **운동 ↔ 수면 ↔ 지출 ↔ 신앙**: 기록을 둘로 나눠 비교해요. 예) 운동한 날 다음 아침의 수면 평점, 잘 잔 날의 러닝 페이스, 잘 잔 날의 지출. 리뷰에 모아 보이고, 관련 분야 화면에도 가장 뚜렷한 것이 나와요.
- **버킷리스트 ↔ 운동**: 운동 기록을 연결해 두면(예: 한 번에 21.1km, 5km 28분 이내, 하루 100회) 기록이 목표에 닿을 때 자동으로 이룬 것으로 바뀌어요.
- **위시리스트 ↔ 가계부**: 가격이 이번 달 남은 예산 안인지 표시하고, 구입으로 바꾸면 가계부에 지출로 남길지 물어봐요.
- **신앙 ↔ 가계부**: 신앙 화면에 이번 달 헌금·기부 금액이 나와요. (이름에 ‘헌금’ 또는 ‘기부’가 들어간 카테고리)

## 기능

- 운동: 종목 추가·삭제. **러닝은 합계가 아니라 기록 중심**이에요. 거리와 시간(분·초)을 적으면 평균 페이스, 페이스 그래프, 거리별 기록(3km·5km·10km·하프)의 평균과 최고가 나와요.
- 수면: 10점 평점, 나에게 맞는 수면 분석
- 가계부: 월 예산, 카테고리와 세부 항목, 수입, 고정 지출, 지난달 비교
- 신앙: 항목 체크, 기도·말씀 시간, 메모, 기도 제목 응답 표시
- 버킷리스트: 올해·내년·언젠가로 나눠 적고, 이루면 체크
- 위시리스트: 가격, 우선순위, 링크
- 모든 기록은 눌러서 수정·삭제, 라이트·다크 모드, 오프라인 사용(PWA), JSON 백업·복원
- 외부 서버 요청이 없어요 (폰트·분석 도구·광고 없음)

## 러닝 기록은 이렇게 계산해요

- 평균 페이스 = 총 시간 ÷ 총 거리 (시간을 적은 기록만 사용)
- 거리별 기록: 그 거리의 ±10% 안에서 달린 기록을 해당 거리로 환산한 값이에요. 예를 들어 5.2km를 30분에 달렸다면 5km 환산 28분 45초예요. 평균은 최근 30일, 최고는 전체 기간 기준이에요.
- 페이스 그래프는 위쪽일수록 빨라요.

## 점수는 어떻게 계산하나요

점수는 "내가 정한 기준을 얼마나 지켰는지"를 0~100으로 보여줘요. 영역마다 기록이 3일 이상 쌓여야 점수가 나오고, 그 전에는 비워 둬요.

| 영역 | 계산 |
| --- | --- |
| 체력·근력 | 최근 7일 운동 합계 ÷ 주간 목표 (100점 상한) |
| 회복 | 기록한 밤 중 목표 수면 시간 이상 잔 밤의 비율 (평점은 점수에 넣지 않고 따로 표시) |
| 꾸준함 | 최근 7일 중 하나라도 기록한 날의 비율 |
| 재정 | 최근 30일 지출을 그 기간의 월 예산 몫과 비교 (예산 안이면 100점) |
| 신앙 | 켜 둔 항목을 최근 7일 동안 실천한 비율 |
| 종합 | 점수가 나온 영역의 평균 (2개 영역 이상) |

버킷리스트와 위시리스트는 점수에 넣지 않아요.

기본값으로 참고한 기준: 성인 수면 하루 7시간 이상(미국수면의학회·수면연구학회 권고), WHO 신체활동 권고(성인 주 150분 이상 유산소, 주 2일 이상 근력). 나머지는 내가 정한 목표가 기준이에요. 의학·재정 진단이 아니에요.

분야 간 연결은 최근 8주 기록을 둘로 나눠 평균을 비교한 값이에요. 각 그룹이 4일 이상이고 차이가 뚜렷할 때만 보여주며, 원인이 아니라 함께 나타난 경향이에요.

## GitHub Pages로 올리는 방법

1. GitHub에서 새 저장소(Repository)를 만들어요. 공개(Public)로 만들면 무료 Pages를 쓸 수 있어요.
2. 이 폴더 안의 파일을 **폴더째가 아니라 파일 그대로** 저장소 맨 위에 올려요.
   (`index.html`이 저장소 맨 위에 있어야 해요. 웹에서 **Add file → Upload files**로 끌어다 놓으면 돼요. 숨김 파일 `.nojekyll`은 없어도 동작해요.)
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `(root)`로 선택하고 Save를 눌러요.
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소로 열려요.

이미 올려 둔 저장소가 있다면 같은 이름의 파일을 덮어쓰기로 다시 올리면 돼요. 기록은 브라우저에 그대로 남아요.

## 폰·태블릿에서 앱처럼 쓰기

- **Android (Chrome)**: 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**

```bash
# 브라우저에서 http://localhost:8000 열기 (창을 넓히면 태블릿 화면이 보여요)
```

## 데이터 저장과 백업

- 기록은 **브라우저별·기기별**로 따로 저장돼요. 폰과 태블릿은 서로 이어지지 않아요.
- 브라우저의 사이트 데이터를 지우면 기록도 사라져요. **설정 → 데이터 내보내기**로 가끔 백업해 두세요. 신앙 메모 같은 개인 기록도 같은 파일에 들어가니 보관에 주의하세요.
- 폰에서 태블릿으로 옮길 때는 한쪽에서 내보내고, 다른 쪽에서 **데이터 가져오기**를 쓰면 돼요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 틀 (아래 탭, 사이드 메뉴 자리 포함) |
| `style.css` | 디자인. 맨 위 `:root`에서 색상 변수를 바꿀 수 있고, 맨 아래 `@media` 블록이 태블릿 가로 배치예요 |
| `app.js` | 앱 전체 로직 |
| `sw.js` | 오프라인 캐시. 파일을 고쳐 올렸다면 안의 `CACHE` 버전 숫자를 올려 주세요 |
| `manifest.webmanifest`, `icon*.png`, `icon.svg`, `apple-touch-icon.png` | 홈 화면 설치용 설정과 아이콘 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서비스하도록 하는 빈 파일 |

## 직접 고쳐 쓰기

- **태블릿으로 바꾸는 기준 크기**: `app.js`의 `TABLET_Q`와 `style.css` 맨 아래 `@media` 두 곳을 함께 바꿔요.
- **2단 나누는 위치**: 각 화면 함수 안의 `<!--cols-->`(2단 시작)와 `<!--col-->`(오른쪽 단 시작) 표식
- **점수 계산식**: `growthAt` 함수, 설명 문구는 `ABIL` 배열
- **분야 간 연결 분석**: `crossInsights` 함수 (최소 일수는 `LINK_MIN`)
- **기본 종목·카테고리·신앙 항목**: `defaultState` 함수 (처음 여는 브라우저에만 적용돼요)
- **색상**: `style.css` 맨 위의 변수
